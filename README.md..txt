## 2. Project Overview

The Hotel Room Booking System is a console-based software application developed using C++. It is designed to manage hotel room information and simplify the room reservation process. Users can view available rooms, search for suitable rooms, create bookings, check booking details, and cancel reservations.

## 3. Main Features

- Display hotel room inventory.
- Search rooms based on booking requirements.
- Check room availability for selected dates.
- Create new room reservations.
- Generate unique booking IDs.
- View booking details using booking IDs.
- Cancel existing reservations.
- Maintain booking history.
- Calculate booking bills with applicable tax.
- Store room and booking information using text files.

## 4. Technologies Used

- Programming Language: C++
- Standard: C++17
- Concepts: Object-Oriented Programming
- Data Structures: STL Vector
- File Handling: Text File Storage
- Development Environment: C++ Compiler / IDE

## 5. Software Requirements

- Windows, Linux, or another compatible operating system.
- C++17-compatible compiler.
- IDE or text editor such as Visual Studio Code, Code::Blocks, or Visual Studio.

## 6. How to Compile and Run

1. Open the project folder in your IDE or terminal.
2. Open the main C++ source file.
3. Compile the program using a C++17-compatible compiler.

Example command:

`g++ main.cpp -std=c++17 -o hotel`

4. Run the generated program:

**Windows:**
`hotel.exe`

**Linux:**
`./hotel`

*Note: Replace `main.cpp` with the actual name of your source file if it is different.*

## 7. Data Storage

The system uses text files to store information:

- `rooms.txt` – Stores hotel room details.
- `bookings.txt` – Stores reservation records.

## 8. Project Limitations

- The application works through a console interface.
- It does not use an online database.
- Payment is simulated for demonstration purposes.
- Data is stored locally in text files.
